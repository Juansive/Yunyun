芸芸は、あなたがタイピングしているあいだそばにいて、新着メールを見張り、「どんなメールが来たか」をひとことで教えてくれます。
アシスタントモードをオンにすると、おしゃべり、調べもの、コードの修正、画面の確認、アプリの起動と操作、ブラウザでの Web 閲覧まで手伝ってくれます。

> キャラクターの絵はまだ仮のものです。正式なイラストを準備中です。

## できること

- **そばにいる**：あなたが入力すると一緒に「キーボードを打ち」、手を止めるとうたた寝し、話すときは口をぱくぱくさせます。デスクトップのどこにでもドラッグできます。
- **メールを見張る**：新着メールが届くと、芸芸の肩に**赤いバッジ**が出ます。QQメールは 15 秒以内、プッシュ通知に対応したメール（Gmail など）は数秒以内、プッシュ非対応のメール（163メールなど）は 2 分ごとに確認します。QQメール・163メール・Gmail に対応しています。
- **ひとことで通知**：バッジをクリックすると、芸芸が AI で 1 通ずつひとことにまとめ（例：「王先生から：論文の第 3 章を補足して月曜までに送ってほしいそうです」）、カードとして順番に見せてくれます。
- **じゃまをしない**：ほかのウィンドウに隠れると自動で一時停止。全画面の動画・ゲーム・スライド中は通知を出しません。おやすみモード（夜間など）を設定すると眠ります。
- **あとから見返せる**：表示した通知は 7 日間保存されます。
- **メールボックスを変更しない**：芸芸が読んだメールも、メールボックスでは「未読」のままです。
- **AI アシスタント**（0.6 から、フル版のみ）：右クリック →「✦ アシスタントモード」。ご自身の DeepSeek / Claude の API キーを使います（従量課金）。詳しくは[アシスタントモード](#アシスタントモード)へ。
- **見守りモード**：あなたが Claude Code を使っているとき、作業が終わったり確認待ちになったりすると芸芸が知らせます。
- 画面は日本語・English・中文に対応（右クリック → 設定… → 一般 → 言語）。

## ダウンロードとインストール

Windows 10/11（64 ビット）が必要です。**Python のインストールは不要です。**

1. このページ右側の **Releases**（または[こちら](https://github.com/Juansive/Yunyun/releases/latest)）を開き、最新バージョンの Assets から 2 種類のどちらかを選びます：

   | ファイル | サイズ | 内容 |
   |---|---|---|
   | **`Yunyun-<バージョン>-windows-lite.zip`**（ライト版） | 約 35 MB、展開後 約 80 MB | デスクトップペット、新着メール通知、見守りモード。**メール通知だけでよければこちら** |
   | **`Yunyun-<バージョン>-windows.zip`**（フル版） | 約 210 MB、展開後 約 490 MB | 上記すべて＋アシスタントモード（増えた分はアシスタントが使う Claude Code、ブラウザドライバー、音声です） |

   好きな場所（例：`D:\芸芸`）に展開します。まずライト版を使って、あとでアシスタントモードが欲しくなったらフル版をダウンロードしてフォルダーを置き換えるだけで OK。設定はそのまま残ります。
   > ⚠️ ページ上の緑の **Code → Download ZIP** は押さないでください。それはソースコードで、Python がないと動きません。
2. フォルダー内の **`芸芸.exe`** をダブルクリックします。フォルダーごとまとめて置いてください（exe だけを取り出すと、隣の `_internal` のファイルが使えず動きません）。
3. 初回起動時に「Windows によって PC が保護されました」と表示されることがあります（芸芸は有料のコード署名をしていないため）。**詳細情報 → 実行** を押してください。
4. 芸芸が現れたら、**芸芸を右クリック → 設定… → 一般** で、デスクトップのショートカットを作ったり、Windows 起動時に開始するよう設定できます。

**新しいバージョンへの更新**：新バージョンが出ると芸芸が教えてくれて、右クリックメニューのいちばん上に **⬆ 新バージョン … をダウンロード** が出ます（設定 → 情報 の「更新を確認」でも確認できます）。
ダウンロードしたら、芸芸を右クリック →「終了」をすばやくダブルクリックし、古いフォルダーを新しいものに置き換えるだけです。メール・AI の設定や履歴は `%APPDATA%\Yunyun` にあるので消えません。
フォルダーの場所を変えた場合は、設定… → 一般 でデスクトップのショートカットを作り直し、「Windows 起動時に開始」をもう一度オンにしてください（古い場所を指したままのため）。

## ソースから実行（開発版）

Windows 10/11 と Python 3.11 以上が必要です。プロジェクトのフォルダーでターミナルを開きます：

```
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m yunyun.main
```

芸芸が現れたら、**右クリック → 設定… → 一般 → デスクトップのショートカット「作成」**。以後はデスクトップの「芸芸 Yunyun」をダブルクリックするだけで、ターミナルは不要です。

## はじめての設定

1. **メールアカウントを追加**：初回起動時に設定ウィンドウの「メール」ページが自動で開きます（あとから 右クリック → 設定… → メール でも変更できます）。
   メールアドレスを入力すると種類が自動で選ばれます。QQメールは QQ のパスワードではなく**認証コード**が必要です：QQメール（Web版）→ 設定 → アカウントとセキュリティ →「IMAP/SMTPサービス」を有効化 → 認証コードを生成。
   163メールも認証コード、Gmail は「アプリパスワード」（先に 2 段階認証をオンに）を使います。設定ページの説明にあるリンクから直接開けます。
2. **AI の設定**（任意・おすすめ）：メールを追加すると、設定ウィンドウが自動で「AI」ページに移ります（あとから 右クリック → 設定… → AI でも変更可）。標準は Zhipu の無料モデルです。
   [open.bigmodel.cn](https://open.bigmodel.cn) で登録し、「API Keys」でキーを作って貼り付けてください。
   AI を設定しなくても使えます。その場合は「誰から、どんな件名のメールが来たか」をそのまま伝えます。
   **メールを PC の外に出したくない場合**：「ローカルモデル（Ollama）」を選びます。先に [ollama.com/download](https://ollama.com/download) から Ollama をインストールしてください。
   登録もキーも不要です。**芸芸はメールを処理するときだけ Ollama を起動し、終わって 20 秒後に止める**ので、普段はメモリを使いません。処理中は一時的に約 1～2 GB 使い、
   Ollama を常に起動しておく場合より 1 秒ほど遅くなります。専用 GPU があればずっと速くなります。
   Ollama はインストール後、標準で Windows 起動時に常駐します（約 160 MB）。芸芸だけで使うなら、タスクマネージャー →「スタートアップ アプリ」で自動起動をオフにできます。
   **自分のモデルを使いたい場合**：「カスタム」を選び、API の URL（OpenAI 互換のサービスなら何でも。たいてい `/v1` で終わります）とモデル名を入力します。キーは空欄でも構いません。
   オンラインなら DeepSeek（`https://api.deepseek.com/v1`）、自分の PC なら LM Studio（`http://localhost:1234/v1`）など。
   PC 内や LAN のアドレスなら、メールがインターネットに出ることはありません。

## 毎日の使い方

| したいこと | 操作 |
|---|---|
| 新着メールを見る | 芸芸の肩の**赤いバッジ**をクリック |
| 今回のメールは見ない | バッジを**ドラッグして離す**（QQ のように）、または 芸芸を右クリック → すべて確認済みにする |
| バッジをしばらく隠す | バッジを**右クリック**。戻すときは**芸芸を右クリック** |
| カードを見る | **ホイール**か ↑↓ キーで切り替え。**カードをクリック**すると件名・差出人・添付が見られます。メールアカウントが 2 つ以上あるときは、カード右下の小さなタグにどのアカウントで受信したかが出ます |
| カードを閉じる | ほかの場所をクリック、Esc、またはバッジをもう一度クリック |
| さっきの通知をもう一度見る | 芸芸を右クリック → **さっきのメール** |
| 以前の通知を見る | 右クリック → 設定… → **履歴**（直近 7 日分） |
| 夜はそっとしておいてほしい | 右クリック → 設定… → 一般 → **おやすみモード**（標準は 23:00～08:00）。そのあいだ芸芸は眠り、新着メールは静かに数えるだけ。あなたが入力すると起きてそばにいます |
| 芸芸がウィンドウに隠れた | タスクバー右下のトレイにある芸芸のアイコンをダブルクリック |
| 芸芸を常に手前に | 右クリック → 設定… → 一般 → 常に最前面 |
| 芸芸を大きく / 小さく | 右クリック → 設定… → 一般 → 芸芸の大きさ（50%～200%。ドラッグ中にすぐ反映。吹き出しやカードの大きさは変わりません） |
| Windows 起動時に開始 | 右クリック → 設定… → 一般 → Windows 起動時に開始 |
| 場所を変える | 芸芸をそのままドラッグ。次回もその場所に現れます |
| 終了 | 右クリック →「終了」を**すばやくダブルクリック**（誤操作防止） |

バッジが数えるのは、**芸芸がメールボックスを見始めてから届いた**未読メールだけです。それ以前にたまっていた未読は数えません。

## アシスタントモード

> 0.6 から、フル版のみの機能です（[ダウンロードとインストール](#ダウンロードとインストール)を参照）。ライト版の右クリックメニューにはこの項目がありません。

芸芸を右クリック → いちばん上の **✦ アシスタントモード**。芸芸の足もとに淡い青の光をまとった入力欄が開き、質問できます。必要なら Web で調べてくれます。
「頭脳」は標準で Claude（Anthropic）、より安い **DeepSeek** にも切り替えられます。**どちらもご自身の API キーが必要で、従量課金です**（Claude の API は Claude のサブスクリプションとは別料金です）。

1. キーを用意する：
   - **DeepSeek**（安価。中国での登録・支払いが簡単）：[platform.deepseek.com](https://platform.deepseek.com/api_keys) → 電話番号で登録 → チャージ（Alipay / WeChat Pay）→ API keys → 作成。
   - **Claude**：[platform.claude.com](https://platform.claude.com) → 登録 → Billing でチャージ（米ドル決済できるカードが必要）→ API Keys → Create Key。
2. 芸芸を右クリック → 設定… → **アシスタント**：サービスを選んでキーを貼り付け、「テストして保存」（キーとモデルを確認するだけで**料金はかかりません**）。標準は最も安い Claude Haiku 4.5 です。
   DeepSeek は Web 検索ができません（渡した URL は読めます）。設定ページにアカウント残高が表示されます。

| したいこと | 操作 |
|---|---|
| 質問する | 入力欄に入力して Enter で送信（Shift+Enter で改行）。芸芸は考えながら、頭の上の吹き出しで回答の出だしを話します |
| 止める | 回答中に入力欄右の ■ をクリック。入力欄が閉じているときは 芸芸を右クリック →「■ アシスタントを停止」。実行中のコマンドも一緒に止まります |
| 回答を全部読む | 1 回のやり取りが 1 枚のカードになって芸芸のそばに並びます。ホイールでめくり、**カードをクリック**すると横に全文が開きます。コードブロックにはコピーボタンがあります |
| 話題を変える | カードの上にマウスを乗せ、右上の「+ 新しい会話」をクリック、または入力欄で Ctrl+N。カードには今の会話だけが並び、前の会話は履歴にあります |
| 昨日の話の続き | 芸芸を右クリック →「会話の履歴…」（またはカード右上の「履歴」）：日付ごとに会話が並びます。開くと全部のやり取りが見られ、「続きから」で前回の続きに戻れます（その会話の作業フォルダーにも自動で戻ります）。30 日間保存 |
| コードを直してもらう | 入力欄左の**フォルダーボタン**で作業フォルダー（例：あなたのプロジェクト）を選びます。中のファイルを読んだり検索したりでき、ファイルの変更やコマンドの実行の前には必ず確認します |
| 許可 / 拒否 | 芸芸の横に確認カードが出ます：コマンドの全文、または変更内容（赤が削除、緑が追加）。「今回だけ許可」、この会話では許可、「拒否」（理由も書けます）から選べます。ファイル削除・ソフトのインストール・ネットからのダウンロードのようなコマンドは赤く表示され、毎回確認します |
| 何をしたか見る | そのやり取りのカードを開き、「▸ 芸芸がしたこと（N 件）」をクリック：読んだファイル、実行したコマンド、それぞれ確認なし / あなたが許可 / 拒否のどれだったか |
| 変更を取り消す | そのやり取りのカードを開き、下の「↶ この変更を取り消す」をクリック（2 回）。取り消せるのはファイル編集ツールでの変更だけで、コマンドによる変更（コマンドが作った / 消したファイルなど）は戻せません。git で戻してください。新しい会話を始めた後は取り消せません |
| 呼び出す | 初回：右クリック →「✦ アシスタントモード」。2 回目からは**芸芸を左クリック**するだけ |
| しまう | Esc かほかの場所をクリック：入力欄だけが引っ込み、カードと開いた全文は**残ります**（資料と見比べるのに便利）。入力中の文字や画像があるときは、ほかをクリックしても閉じません（Esc で閉じます）。エクスプローラーからファイルをドラッグしてくるときも閉じません |
| カードを隠す | 芸芸を右クリック →「カードを隠す」。芸芸を左クリックすると戻ります（開いていた全文も一緒に） |
| カードを動かす | カードや全文パネルの何もないところをドラッグ（画面の外には出ません）。以後、カードは芸芸からその位置を保ってついてきます。右クリック →「カードを芸芸のそばに戻す」で元に戻ります |
| 画面を見てもらう | 「画面のこのエラーを見て」と言うと、「ちょっと画面を見るね」と言って直前に使っていたウィンドウ（必要なら画面全体）を撮ってから答えます。芸芸自身のウィンドウは写りません。標準では確認なし。設定 → アシスタント →「スクリーンショットの前に確認する」をオンにすると毎回確認します |
| 知らせてもらう | 「25 分後に呼んで」「毎日午後 3 時に水を飲むよう知らせて」「平日 9 時に会議を知らせて」と言えば、確認なしで設定し、時間になると吹き出しと Windows の通知で知らせます（アシスタントモードが開いていれば読み上げも）。芸芸が起動していなかったときの分は、次に起動したときに知らせます。設定 →「リマインダー」で確認・削除でき、あるときは右クリックメニューに「リマインダー（N）…」が出ます |
| クリップボードとウィンドウ | 「これをクリップボードに入れて」：確認なしで入れるので自分で貼り付けます。「今コピーしたのを見て」：毎回確認します（パスワードが入っているかもしれないため）。「開いているウィンドウは？」「WeChat に切り替えて」「Word を最小化して」：一覧・切り替え・最小化・元に戻すは確認なし（ウィンドウのタイトルはプロバイダーに送られます）。ウィンドウを閉じることはしません |
| アプリを開いてもらう | 「電卓を開いて」と言うと、スタートメニューから名前で探し、まず確認します（カードにアプリ名が出ます）。そのアプリだけこの会話中は許可、も選べます。開けるのはスタートメニューにあるものだけです |
| アプリの中を操作してもらう | 「電卓で 7+8 を計算して」「メモ帳で保存を押して」と言うと、まずウィンドウのボタンや入力欄を読み取り（確認なし。スクリーンショットと同じくプロバイダーに送られます）、ボタンを押す・入力する・ショートカットを押す前に確認します（カードにアプリと押すボタン / 入力する文字が出ます）。そのアプリだけこの会話中は許可、も選べます。送信・削除・支払い・閉じる・Enter は毎回確認し、赤く表示します。チャットアプリ（WeChat、QQ など）では入力だけで送信はしません。パスワード欄、ターミナル、「ファイル名を指定して実行」、セキュリティ設定には触れず、マウスも動かしません。独自の画面を描くアプリ（新しい WeChat など）は中を読めないので、スクリーンショットで見ます |
| ブラウザを使ってもらう | 「xxx のサイトを見て」と言うと、自分専用の Edge ウィンドウを開いて（あなたにも見えます）、読んでから答えます。あなたのブラウザとは別で、そこでログインしたサイトは次回もログインしたまま。パスワード欄やカード番号欄の中身は芸芸に見せません。ブラウザを開いているあいだはバックグラウンドを解放しません。ページによって 0.4～1 GB 以上使うので、**使い終わったらそのウィンドウを閉じてください** |
| Web ページで操作してもらう | 「Bilibili で猫を検索して」「このフォームを埋めて」など：クリック・入力・選択の前に毎回確認します（カードにサイトと押すボタン / 入力する文字が出ます）。この会話中はそのサイトで全部許可、も選べます。送信・注文・支払い・送付・削除・ダウンロードは毎回確認し赤く表示します（検索は含みません）。パスワード・カード番号・認証コードは芸芸は入力しないので、ご自身でウィンドウに入力してください |
| ファイルをダウンロードしてもらう | 毎回まず確認し、ファイルは「ダウンロード」フォルダーに保存します（同名のときは「名前 (1).zip」のようにして上書きしません）。芸芸のブラウザであなた自身がダウンロードしたものもそこに入り、終わると教えてくれます |
| 画像を見せる | 入力欄に Ctrl+V でコピーした画像を貼るか、画像ファイルをドラッグ：入力欄の上にサムネイルが出て（× で削除）、文章と一緒に送られます（一度に 5 枚まで）。画像以外のファイルをドラッグするとパスが入ります |
| 覚えてもらう | 「覚えておいて…」と言えば必ず覚えます。普段から役立つこと（あなたの好み、プロジェクトの決まり、ハマりどころ）を**メモ帳**に書き留めるので、別の会話でも覚えています。「あなたについて」のメモは全部の会話で、プロジェクトのメモは同じ作業フォルダーでだけ使います。設定 →「メモ帳」で見る・直す・消す・オフにするができます |
| だんだん分かってくれる | 新しい会話を始めるたびに前の会話を振り返り、「あなたとの付き合い方」を付き合いメモに残します（呼び方・口調・冗談の加減・疲れたときにどうしてほしいか）。自分で気づいたことは 2 つの会話で出てきてから使い、あなたがはっきり頼んだことはすぐ使います。新しいメモを使い始めると吹き出しで知らせます（1 日 1 回まで）。振り返るときはその会話の一行要約も書きます（**思い出**、1 年間）。最新の 5 件は毎回の会話に付くので話をつなげられ（「この前の発表の準備、どうだった？」）、それより前はあなたが聞けば芸芸が自分で調べます（30 日以内なら当時のやり取りも読めます）。設定 →「メモ帳」で見る・直す・消す・オフにするができ、「履歴を消去」で思い出も消えます。振り返るときは質問と回答を選んだプロバイダーに送ります（いちばん安いモデル、ふつう 1 セント未満） |
| 性格 | 標準では、ちょっとツンデレでかわいい小さな精霊です（本題はきちんと説明し、あなたが落ち込んでいるときはツンデレをやめます）。設定 → アシスタントの「あなたの呼び方」で呼び方（例：「ご主人さま」）を設定できます。「芸芸の性格」の下の欄に補足（例：「たとえ話で説明して」）を書くか、「自分で設定」でまったく新しい性格を書けます。新しい会話から反映されます |
| 話しかける | 設定 →「音声」で「話すキー」（例：Ctrl+Shift+Space や F9）を決めて、音声認識モデルを「ダウンロード」（約 240 MB、1 回だけ）。あとはアシスタントモードでキーを押しながら話し、離すと送信。返事も声で返ってきます。押しているあいだ芸芸は「聞いている」姿になり、頭の上で音量バーが動きます。芸芸が話している途中でも、押せば止まって聞いてくれます。キーはアシスタントモードを開いているときだけ有効で、おやすみ時間は無効です |
| 呼びかける | 右クリック →「いつも聞く」（または 設定 →「音声」）をオンにするとキー不要：「芸芸、……」と言えば質問になります。「芸芸」とだけ呼ぶと返事をして、次のひと言を聞いてくれます。声で聞いたときは、答えたあと数秒間も名前を呼ばずに続けて話せます（マイクのまわりの緑の輪がカウントダウン。設定 →「音声」→「続けて話す」で 3 / 5 / 8 秒。「えー」「うん」だけは送りません）。オンのあいだは芸芸の左上に緑の小さなマイクが出ます。「芸芸」で始まらない言葉はこのパソコンで認識してすぐ捨てます。全画面のとき・おやすみ時間は聞きません。芸芸が話しているときに「やめて」と言うか「芸芸」と呼べば止められます（ヘッドホンだと確実。スピーカーなら少し大きめの声で） |
| 芸芸に言ったんじゃない言葉を拾われた | 回答表示欄の「🙈 あなたに言ったんじゃない」か、右クリック →「さっきの言葉を取り消す（芸芸に言ったんじゃない）」：そのカードが消え、芸芸もその質問を忘れます（声で聞いた一番新しいカードだけ） |
| 声で返事してもらう | 初期設定では声で聞いたときだけ声で返事します。設定 →「音声」で「声で返事」を「毎回」にすると、文字で聞いても読み上げます。本文だけ読みます（コード・表・URL は読まず、ファイルパスはファイル名だけ）。芸芸の声は一種類だけです（中国語の「暁伊」を少し高くしたもの。日本語の画面でも同じ声なので、日本語の発音は少し不自然です）。「試聴」で先に聞けます。右クリック →「話すのをやめる」で止まり、新しい質問・停止・話すキーでも止まります。もう一度聞きたいときは、回答表示欄の「🔊 読み上げる」か、右クリック →「さっきの回答をもう一度読む」 |
| 終了 | 右クリック → アシスタントモードを終了。入力欄を閉じたまま 10 分たつと、先にバックグラウンドを解放します（約 300 MB）。カードは残り、また質問すると自動でつながって同じ会話を続けます |

- **料金**：Haiku 4.5 なら 1 回の質問でたいてい 1 米セント前後です（会話の最初の質問は少し高め）。設定ページで「1 回の回答の上限」（標準 $0.1）と
  「1 つの会話の上限」（標準 $0.5）を変えられ、芸芸が今日 / 今月 / 合計でいくら使ったかも見られます。Anthropic には残高を調べる API がないので、残高は公式サイトで確認してください。
  DeepSeek なら 1 回あたりたいてい 0.01～0.03 人民元（実測 約 $0.002～0.005）。料金は芸芸が DeepSeek の価格で計算します（多めに見積もるためピーク時の価格で）。
  たくさん作業させる（多くのファイルを読む、コマンドを実行する、Web を見る）と 1 回あたり高くなります。
- **会話が長くなったら**：1 つの会話が約 4 万トークンを超えると、芸芸は回答のあとで前半を要約し、以後は要約だけを持って続けます（賢さを保ち、安くなります。
  細かい点が抜けることもあります）。カード下の「会話 2.3万/4万」が今の長さです。設定 → アシスタント →「長い会話を自動で整理」で長さを変えたりオフにしたりできます。
- **メモリ**：アシスタントモードを開いているときだけ約 360 MB 増えます（うち Claude Code が約 300 MB）。終了すれば全部戻ります。
- 作業フォルダーを選ばないときは、おしゃべりと Web 検索だけができます。作業フォルダーに `CLAUDE.md`（プロジェクトの説明）があれば従いますが、`.claude\` 内の設定は読み込みません。何を確認するかは芸芸だけが決めます。
- アプリの中ではボタンを押す・入力する・キーを押すだけで、マウスは動かしません。独自の画面を描くアプリ（新しい WeChat、ゲームなど）は中を読めず、スクリーンショットで見るだけです。

## 見守りモード：あなたの Claude Code を芸芸が見ていてくれる

あなた自身がターミナル、VS Code、Claude デスクトップ版で Claude Code を使っているとき、芸芸が代わりに見ていてくれます：**1 ターン終わったとき、権限の確認を待っているとき、選択肢を選んでほしいとき**に
芸芸が知らせます（「Claude Code 完了 · プロジェクト名」、その下に最初のひとこと）。**そのウィンドウを見ているときは知らせません**。芸芸がほかのウィンドウに隠れているときは、
タスクバー右下の上に小さなバーが出て、クリックすると Claude Code に切り替わります。アシスタントモードを開く必要はなく、どちらの版でも使えます。

- オンにする：設定 →「見守り」→「Claude Code に接続」。`C:\Users\あなた\.claude\settings.json` にフックを 2 つ追加します
  （終わったとき・確認待ちのときに芸芸の小さなスクリプトを実行します。数十ミリ秒で終わり、芸芸が起動していなければ何もしません）。変更前に同じフォルダーへバックアップし、あなた自身のフックやほかの設定には触れません。
- すでに開いている Claude Code は開き直すと有効になります。「テスト通知を送る」で見た目を確認できます。
- やめたいとき：「切断」で芸芸が追加した 2 つだけを削除します。

## プライバシー

| データ | 保存場所 |
|---|---|
| メールの認証コード、AI の API キー、アシスタントの API キー | Windows 資格情報マネージャー（`yunyun-mail`、`yunyun-ai`、`yunyun-assistant`）。Windows アカウントで暗号化・保護されます |
| アシスタントの会話記録 | `%APPDATA%\Yunyun\Yunyun\assistant\claude\`（Claude Code 自身のセッション記録。**会話の全文と、芸芸が画面を見たときのスクリーンショットを含みます**） |
| アシスタントの回答カード（会話の履歴） | `%APPDATA%\Yunyun\Yunyun\assistant\cards.json`（**質問と回答の全文、行った操作を含みます**）。上の会話記録・取り消し用バックアップと同じく **30 日間保存**。設定 → アシスタント →「履歴を消去」ですぐに全部消せます |
| 取り消し用のファイルのバックアップ | 同じフォルダー内（Claude Code がファイルを変更する前に元のファイルを保存し、取り消しに使います。30 日間保存） |
| 芸芸のブラウザ | `%APPDATA%\Yunyun\Yunyun\assistant\browser\`（Edge のプロファイル：**そこでログインしたサイト、閲覧履歴、Cookie**。自動では消えません。消したいときはアシスタントモードを終了してからこのフォルダーを削除） |
| 作業フォルダー（直近 5 つ） | `%APPDATA%\Yunyun\Yunyun\config.yaml` |
| 芸芸のメモ帳 | `%APPDATA%\Yunyun\Yunyun\assistant\memory.json`（芸芸が書き留めたこと。設定 → メモ帳 →「すべて消去」で削除） |
| アシスタントの利用金額 | `%APPDATA%\Yunyun\Yunyun\assistant_spending.json`（日付と金額だけ） |
| メールアドレス、AI のサービス | `%APPDATA%\Yunyun\Yunyun\config.yaml` |
| どのメールを通知したか | `%APPDATA%\Yunyun\Yunyun\mail_state.json`（メールの番号だけで、内容はありません） |
| 通知の履歴 | `%APPDATA%\Yunyun\Yunyun\history.db`（AI のひとこと、件名、差出人、日時、添付ファイル名、受信アカウント。本文は含みません。7 日間保存） |
| ログ | `%APPDATA%\Yunyun\Yunyun\logs\`（メールの内容やキーは含まず、メールアドレスは伏せ字） |
| 言語、ウィンドウ位置などの設定 | レジストリ `HKEY_CURRENT_USER\Software\Yunyun` |
| Windows 起動時に開始 | 「スタートアップ」フォルダー内の「芸芸 Yunyun」ショートカット |

- **AI に送る内容**：**バッジをクリックしたときだけ**、メールの差出人・件名・添付ファイル名・本文の冒頭（最大 1,500 文字）を選んだ AI サービスに送ります。バッジをドラッグして消したメールは送りません。
  「ローカルモデル（Ollama）」なら PC 内の Ollama にだけ渡し、インターネットには出ません。「カスタム」なら入力したアドレスに送ります（PC 内や LAN のアドレスならインターネットには出ません）。
- **AI に渡したくないメール**：設定 → AI のいちばん下の「プライバシー」で、メールアカウントごと、または差出人アドレス / `@ドメイン`（例：`@icbc.com.cn` ならそのドメインからのメールすべて）を指定できます。これらのメールは差出人と件名だけを表示し（🔒 付き）、ローカルモデルを含めどの AI にも一切送りません。
- **新バージョンの確認**：1 日に 1 回まで GitHub（`api.github.com`）に最新のバージョン番号を問い合わせます。リクエストにはアプリ名とバージョンしか含まれず、あなたの情報は一切送りません。設定 → 一般 でオフにできます。
- **通知に機密情報を出さない**：認証コード、受け取りコード、金額、カード番号、注文番号、リンクは、AI が書いてしまっても芸芸が自動で消します（通知はデスクトップに表示され、履歴にも保存されるため）。
- **アシスタントモード**：あなたの質問と会話は選んだサービス（Claude / DeepSeek）に送られ、芸芸が検索・閲覧した Web ページの内容も経由します。作業フォルダーを選んでいれば、
  芸芸が読んだファイルの内容、コマンドの実行結果、プロジェクトの `CLAUDE.md` も送られます。会話の開始時にはメモ帳の目次（1 件 1 行）も送られます。
  画面を見るときはスクリーンショットも送られます（芸芸自身のウィンドウは写りません）。
  声で返事するときは、読み上げる文字が Microsoft の無料オンライン音声に送られます（つながらないときは Windows 標準の声をオフラインで使います）。
  話すキーや「いつも聞く」で聞いた声はこのパソコンの中だけで文字にし、録音はアップロードも保存もしません（文字は入力した質問と同じように送られます）。
  アシスタントモードを開かなければ何も送りません。
- **キーボード**：芸芸が知るのは「入力しているかどうか」だけで、**どのキーを押したかは一切記録しません**。

## よくある質問

**バッジがいつまでも出ない？** 通知するのは新しく届いたメールだけです。別のアカウントから自分宛てにメールを送ってみてください：QQメールは 15 秒以内、Gmail は数秒以内、ほかのメールは最大 2 分で出ます（起動直後やネットが切れた直後は 1～2 分かかることもあります）。芸芸をクリックすると「今は新しいメールはないよ～」と教えてくれます。

**問題を報告するには？** 右クリック → 設定… → 情報 → ログフォルダーを開く から、`yunyun.log` を開発者に送ってください。

**芸芸のデータを完全に消すには？** まず 右クリック → 設定… → 一般 で「Windows 起動時に開始」をオフにします（見守りモードを使っていたら 設定 → 見守り →「切断」も）。芸芸のフォルダー（またはプロジェクトのフォルダー）、デスクトップのショートカット、`%APPDATA%\Yunyun` を削除し、「コントロール パネル → 資格情報マネージャー → Windows 資格情報」で `yunyun-mail`、`yunyun-ai`、`yunyun-assistant` で始まる項目を削除し、レジストリ `HKEY_CURRENT_USER\Software\Yunyun` を削除してください。

## 開発

```
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python -m pytest            # テストを実行
.\.venv\Scripts\python -m yunyun.mail       # デバッグ：コマンドラインで未読メールを読む
.\.venv\Scripts\python tools\make_placeholders.py   # 仮の絵を作り直す
.\.venv\Scripts\python tools\build_exe.py   # exe にパッケージ（tools\build_exe.bat をダブルクリックでも可）
```

2 種類をまとめて作ります：フル版 `dist\芸芸\芸芸.exe`、ライト版 `dist\lite\芸芸\芸芸.exe`（アシスタントモードの部品なし。`build_exe.py lite` / `full` で片方だけ作れます）。
配布用の zip はプロジェクトフォルダーの隣の `..\Yunyun\` に作られます：`Yunyun-<バージョン>-windows.zip` と `Yunyun-<バージョン>-windows-lite.zip`（最新版だけを置き、古いものは `releases\` へ移します）。
ビルドスクリプトは「Python がない」環境で exe のセルフチェックを実行し（フル版は `OK` が 9 行。うち 2 行は実際に Claude Code と非表示の Edge を起動します。
さらに exe を「アシスタントのサブプロセス」として試します。ライト版は 8 行で、最後の行でアシスタントの部品が入っていないことを確認）、すべて通ったときだけ zip にします。
zip には [docs/使用说明.txt](docs/使用说明.txt)（使い方の説明・中国語。バージョン番号を自動で記入）と[更新履歴](docs/更新日志.txt)（中国語）が入ります。開発用のメモは入りません（スクリプトが確認します）。
配布する前に `yunyun/__init__.py` のバージョン番号を上げ、2 つの zip を GitHub の Releases にアップロードします。

- 開発用のメモ（CLAUDE.md、設計の詳細、計画、引き継ぎ）は開発者の PC にだけあり、このリポジトリには含まれません。
- キャラクター素材の要件は [assets/pet/README.md](assets/pet/README.md)（中国語）を参照してください。
