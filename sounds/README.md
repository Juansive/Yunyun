# Optional double-click sounds / 可选的双击音效

These clips are **not bundled** with Yunyun. They are downloaded only when you pick one in
Settings → General ("Sound when you double-click Yunyun").

这几段**不随芸芸自带**，在 设置 → 通用 →"双击芸芸时出声"里选了才下载。

| File | Clip |
|---|---|
| `man.wav` | 172. man |
| `manbo.wav` | 174. 曼波 |
| `chicken.wav` | 175. 公鸡下蛋 |
| `gugugaga.wav` | 233. 咕咕嘎嘎 |

Source / 来源: Bilibili video [BV1PAfEBgESk](https://www.bilibili.com/video/BV1PAfEBgESk/) "250个meme音效合集（补档）",
cut by the numbers shown in the video and level-matched (`tools/make_sounds.py --cut`).
