芸芸 Yunyun {version} · 使用说明
================================

芸芸是一只住在桌面上的小助手：陪你打字，帮你留意新邮件，用一句话告诉你"来了什么邮件"。
打开"助手模式"（完整版才有），她还能当你的 AI 助手：聊天、上网查资料、帮你改代码、看屏幕、打开软件、用浏览器帮你看网页（见第四节）。


一、运行
--------
1. 把整个"芸芸"文件夹解压到你喜欢的位置（比如 D:\芸芸）。
   不要只把"芸芸.exe"拷出来，它要用旁边 _internal 文件夹里的文件。
2. 双击"芸芸.exe"。
3. 第一次运行时如果弹出"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。
   （芸芸没有购买数字签名，所以 Windows 会提醒一下。个别杀毒软件误报时，选"允许"即可。）
4. 芸芸会出现在桌面右下角。右键芸芸 → 设置… → 通用，可以创建桌面快捷方式、设置开机时启动。

系统要求：Windows 10 / 11（64 位）。不需要安装 Python 或其他软件。

芸芸有两种压缩包，用起来一样，区别只在有没有助手模式：
· 节能版（Yunyun-版本-windows-lite.zip，文件夹约 80 MB）：桌宠、新邮件提醒、旁观模式。右键菜单里没有"助手模式"。
· 完整版（Yunyun-版本-windows.zip，文件夹约 490 MB）：再加上助手模式（多出来的是它要用的 Claude Code、浏览器驱动和语音，
  不用助手模式时它们不占内存）。
用着节能版想换完整版：退出芸芸，用完整版的"芸芸"文件夹替换旧的就行，设置和记录都不会丢。


二、第一次使用
--------------
1. 添加邮箱：第一次启动时会自动打开设置窗口的"邮箱"页。填好邮箱地址，"邮箱类型"会自动选好；
   下面说明里的网址点一下就能打开。
   QQ 邮箱要填"授权码"，不是 QQ 密码。获取方法：
   电脑上打开 QQ 邮箱网页版 → 设置 → 账号与安全 → 开启"IMAP/SMTP 服务"→ 按提示生成授权码，复制过来。

2. 设置 AI（可选，推荐）：添加完邮箱后会自动翻到"AI"页，下面两种选一种：
   · 智谱（免费）：打开 open.bigmodel.cn 注册并登录 → 右上角头像 → API Keys → 添加新的 API Key，
     复制到芸芸里，点"测试并保存"。
   · 本地模型（邮件不出电脑，不用注册）：先到 ollama.com/download 下载安装 Ollama；
     服务商选"本地模型（Ollama）"→ 点"测试并保存"→ 点"下载模型"（约 1.4 GB）。
     芸芸只在处理邮件时启动它，用完就关，平时不占内存。
   · 自定义（用你自己的模型）：服务商选"自定义"，填接口地址（任何兼容 OpenAI 接口的服务，一般以 /v1 结尾）和模型名，
     Key 可以不填。比如在线的 DeepSeek：https://api.deepseek.com/v1；自己电脑上的 LM Studio：http://localhost:1234/v1。
   不设置 AI 也能用，芸芸会直接告诉你"谁发来了什么标题"。


三、日常使用
------------
· 看新邮件：有新邮件时芸芸右上角会出现小红点（QQ 邮箱 15 秒内、Gmail 几秒内就会出现），单击小红点。
· 这批邮件不想看了：把小红点拖走松手（像 QQ 那样），或者 右键芸芸 → 全部标为已看。
· 暂时不想看到小红点：右键小红点；想找回来就右键芸芸。
· 浏览卡片：滚轮或 ↑↓ 键切换；单击卡片可以看标题、发件人、附件。点别处或按 Esc 收起。
  添加了两个以上邮箱时，卡片底部右边的小标签写着是哪个邮箱收的（历史记录里也有）。
· 再看一眼刚才的提醒：右键芸芸 → 刚才的邮件；更早的：设置… → 历史（保存 7 天）。
· 晚上别打扰我：设置… → 通用 → 免打扰（期间芸芸睡觉，新邮件只安静地计数）。
· 芸芸太大 / 太小：设置… → 通用 → 芸芸大小，拖动滑块（50%～200%），"恢复默认"回到原来的大小。
· 芸芸被别的窗口挡住了：双击任务栏右下角托盘里的芸芸图标。
· 换个位置：直接拖动芸芸，下次启动还在那里。
· 退出：右键芸芸 → 快速双击"退出"（防止误点）。

小红点只数芸芸开始帮你看邮箱之后新来的邮件，以前的旧邮件不算。
芸芸不会改动你的邮箱：它看过的邮件，在邮箱里仍然是"未读"。

· 用 Claude Code 写代码时让芸芸盯着（旁观模式）：设置… → 旁观 → "连接我的 Claude Code"。
  之后 Claude Code 做完一轮、等你确认或让你选的时候，芸芸会提醒你；你正看着那个窗口时不打扰。
  芸芸被挡住时，任务栏右下角上方会弹一个小条，点一下就切到 Claude Code。已经开着的 Claude Code 要重新打开才生效。
  连接会在 Claude Code 的设置文件（C:\Users\你的用户名\.claude\settings.json）里加两条设置，改之前先备份；
  不想用了点"断开"，只删芸芸加的那两条。


四、助手模式
------------
（只有完整版有。节能版要用的话，换成完整版即可，见第一节。）
右键芸芸 → 第一项"✦ 助手模式"，芸芸脚下会展开一个输入框，可以问她问题，需要时她会上网查资料。
她的"大脑"要用你自己的 API Key，按用量付费（不是免费的），两家选一家：

1. 准备 Key
   · DeepSeek（便宜，在国内注册、付款都方便，推荐）：打开 platform.deepseek.com，用手机号注册登录 →
     "充值"（支付宝 / 微信都行，充十几块钱能用很久）→ 左边"API keys"→"创建 API key"，复制下来（只显示一次）。
     DeepSeek 不能搜索网页，但能读你给的网址。
   · Claude（Anthropic，更聪明一些，贵一些）：打开 platform.claude.com 注册登录 → Billing 充值（要能付美元的银行卡）→
     API Keys → Create Key，复制下来。注意：Claude 的 API 和 Claude 网页版的会员是分开收费的。
2. 右键芸芸 → 设置… → 助手：选服务商，粘贴 Key，点"测试并保存"（只检查 Key 能不能用，不花钱）。
   Key 只存在这台电脑的 Windows 凭据管理器里，保存后输入框里不会再显示。

大概花多少钱：
   · DeepSeek：一般每问一次 1～3 分钱（人民币）。设置页会直接显示你的 DeepSeek 账户余额。
   · Claude（默认最便宜的 Haiku 4.5）：一般每问一次 1 美分左右（约 7 分钱人民币），每段对话的第一问稍贵一点。
   · 让她干活（读很多文件、跑命令、看网页）时一问会贵一些。设置 → 助手 里有两道上限：
     "每次回答最多花"（默认 0.1 美元）和"每段对话最多花"（默认 0.5 美元），到了就停下；也能看到今天 / 本月 / 一共花了多少。

常用操作：
· 提问：在输入框里打字，Enter 发送（Shift+Enter 换行）。芸芸一边想一边在头顶的气泡里说回答的开头；
  回答时点输入框右边的 ■ 就停下。之后左键点一下芸芸就能再叫出输入框。
· 看完整的回答：每一问一答变成一张卡片放在芸芸旁边，滚轮翻看；单击卡片在旁边打开全文，代码块可以一键复制。
· 换个话题：卡片堆右上角"+ 新对话"，或在输入框里按 Ctrl+N。以前的对话在 右键芸芸 →"历史对话…"，
  点"接着聊"就能回到那段对话（保留 30 天）。
· 让她帮你改代码 / 整理文件：点输入框左边的文件夹按钮，选一个"工作文件夹"。她能读里面的文件；
  改文件、执行命令之前都会弹出确认卡片问你（红色是要删掉的、绿色是新增的），可以"允许一次""这次对话都允许"或"拒绝"。
  她改过文件的那一问，打开卡片点"↶ 撤销这次改动"就能恢复（用命令改的撤销不了）。
· 让她看屏幕：说"看看我屏幕上这个报错"，她会截下你刚才用的窗口再回答（她自己的窗口不会被截进去）。
· 让她打开软件：说"帮我打开计算器"，她先问你，同意了才打开（只能打开开始菜单里有的软件）。
· 让她操作软件里面：说"用计算器帮我算一下 7+8""在记事本里点保存"。她先读出窗口里的按钮、输入框（不用确认），
  按按钮、输入、按快捷键之前都先问你（可以"这次对话在这个软件都允许"）；发送、删除、付款、关闭、回车每次都问。
  聊天软件（微信、QQ……）里她只打字，发送你自己按；密码框、终端、"运行"框、系统安全设置她不碰。
  按不下去的按钮她会用鼠标点（屏幕角落有"芸芸在用鼠标"的小条）；你一动鼠标她就停手、把鼠标还给你，要继续就说一声。
  有的软件自己画界面（比如新版微信），她读不到里面：这时按截图上的位置点（确认卡片上有一小块截图、红圈标出要点的地方，
  看清楚再允许；聊天软件里每次都问），点好输入框就能把字打进去，发送还是你自己按。
· 让她用浏览器：说"打开 xxx 网站看看"，她会打开自己的 Edge 窗口（和你平时的浏览器分开）。
  点击、输入之前都会先问你；提交、下单、付款、发送、删除、下载每次都问；密码、卡号、验证码她不填，请你自己填。
  下载的文件存到你的"下载"文件夹。浏览器窗口要占不少内存，用完把它关掉。
· 给她看图片：在输入框里 Ctrl+V 粘贴，或者把图片拖进来。
· 电源和程序："锁屏""让电脑睡一会儿"直接做；"关机""重启"每次先问你，允许以后还留 60 秒，这期间说"取消关机"就不关了。
  "看看谁在吃内存"会列出正在运行的程序；"把记事本关掉"每次先问你（没保存的会丢），芸芸自己和系统程序她不碰。
· 让她记住你：说"记住……"；平时她也会把用得上的事记进"记事本"（设置 → 记事本 里能看、改、删、关掉）。
· 让她提醒你：说"25 分钟后叫我""每天下午 3 点提醒我喝水"。到点她冒气泡、弹 Windows 通知（助手模式开着时还会说出来）；
  她没开着时错过的，下次打开补一句。设置 → 提醒 里能看、能删。
· 剪贴板和窗口："帮我把这段放进剪贴板"（不用确认）、"看看我刚复制的"（每次先问你）；
  "我开着哪些窗口""切到微信""把 Word 最小化"（不用确认，窗口标题会发给服务商；她不会关你的窗口）。
· 她会越来越懂你：每开始一段新对话，她先回想上一段，把"怎么跟你相处"记成相处笔记。她自己观察到的要在两段对话里
  都出现才用上，你明确说过的马上用上。回想时还会给那段对话写一句摘要（回忆，留一年）：最近 5 段她每次都记得，
  更早的你问起来她会自己翻。设置 → 记事本 里能看、改、删、关掉（回想一次一般不到 1 美分）；"清空历史对话"也会清掉回忆。
· 她的性格：默认是有点傲娇、但很可爱的小精灵。设置 → 助手："怎么称呼你"填个称呼；"芸芸的性格"下面能补充几句，
  或者选"自己设定"写一个全新的性格。新开的对话生效。
· 对她说话：设置 → 语音，先设一个"说话快捷键"（比如 Ctrl+Shift+Space 或 F9），再点"下载"识别模型（约 240 MB，只下一次）。
  之后在助手模式里按住快捷键说话，松开就发给她，她也会出声回答。快捷键只在助手模式开着时有用，免打扰时段里不管用。
· 叫她：右键芸芸 →"始终在听"打开后，不用按键，说"芸芸，……"就行（只叫"芸芸"她会应一声，接着说）。开着时芸芸左上角有个绿色小麦克风。
  开头没叫"芸芸"的话在本机识别后马上扔掉；全屏时、免打扰时段不听。
  她说话时也能打断她：说"别说了"她就停；叫一声"芸芸"她停下来听你说；"芸芸，……"直接当成新的问题
  （戴耳机最灵；外放时她自己的声音也会进麦克风，要说得比她大声一点）。
· 误收了不是跟她说的话：阅读框里点"🙈 不是跟你说的"，或者右键芸芸 →"忽略刚才那句"。那张卡片消失，芸芸也忘掉这一问。
  只对最新一张、用语音问的卡片有；她还在回答时也能点。
  用语音问她时，她说完后几秒内接着说不用再叫"芸芸"（小麦克风外面一圈绿条倒数；设置 → 语音 →"接着说"选 3 / 5 / 8 秒）。
  你说话时绿条停在满格，停下来才接着减；一句话中间停一下（不到约 1.5 秒）接着说的都算同一个问题，你停够了她才发出去。
  只说"嗯、哦"这类语气词不会发出去。
· 让她出声回答：设置 → 语音，"芸芸出声回答"默认是"你用语音问时"，改成"每次回答都说"打字问也会读（只读正文：代码、表格、网址不读）。
  芸芸只有一种声线（调高了音调的"晓伊"，日文 / 英文界面也是她），"试听"能先听一下。
  读的时候右键芸芸 →"别说了"就停下；问新问题、点停止、按说话快捷键也会停。
  想再听一遍：点开卡片，阅读框下面的"🔊 读一遍"；或者右键芸芸 →"再读一遍刚才的回答"。
· 收起：按 Esc 或点别处，只有输入框收起，卡片会留着；右键芸芸 →"隐藏卡片"才收起卡片。
· 退出：右键芸芸 →"退出助手模式"。只打开助手模式时才多占内存（约 360 MB），输入框收起 10 分钟没用会先释放，退出后全部还回来。


五、隐私
--------
· 邮箱授权码、AI 的 Key 只保存在这台电脑的 Windows 凭据管理器里，由你的 Windows 账户保护。
· 只有你点了小红点，才会把邮件的发件人、标题、附件名和正文开头（最多 1500 字）发给你选的 AI 服务商；
  选"本地模型"时，邮件只在你的电脑上处理，不会发到网上；选"自定义"时，发给你填写的地址
  （本机或局域网的地址同样不会发到网上）。
· 有些邮件不想交给 AI：设置 → AI 最下面的"隐私"，可以勾选整个邮箱，或者填发件人地址 / @域名
  （比如 @icbc.com.cn，这个域名发来的都算）。这些邮件只显示发件人和标题（带 🔒），一个字都不发给 AI，本地模型也不给。
· 提醒里不会出现验证码、取件码、金额、卡号、订单号、链接（AI 写了芸芸也会自动删掉）。
· 芸芸只检测"你有没有在打字"，从不记录你按了哪个键。
· 新版本提醒：每天最多问一次 GitHub 最新的版本号，不发送你的任何信息；不想要可以在 设置 → 通用 取消"自动检查新版本"。
· 旁观模式：Claude Code 把"做完了 / 等你确认 + 项目名 + 它说的第一句"交给芸芸，只在你的电脑里传，不上网，也不保存。
· 助手模式：你的提问会发给你选的服务商（DeepSeek / Claude）；她读的网页、你选的工作文件夹里她读的文件、
  执行命令的结果、她看屏幕时的截图、记事本的目录也会发过去。不打开助手模式就什么都不发。
  出声回答时，要读的回答文字会发给微软合成声音（免费的在线语音）；连不上时用 Windows 自带的声音（不联网）。
  按住快捷键说的话、始终在听时听到的话只在你的电脑里识别成文字，录音不上传、不保存（叫了"芸芸"的那句识别出的文字和打字一样发给服务商）。
  对话记录、问答卡片、改文件前的备份保存 30 天（设置 → 助手 →"清空历史对话"可以马上删掉）；
  她的浏览器里登录过的网站、Cookie 会留着（在 %APPDATA%\Yunyun\Yunyun\assistant\browser，想清掉就退出助手后删这个文件夹）。
· 设置和记录都保存在你自己电脑的 %APPDATA%\Yunyun 文件夹里，不会上传。


六、常见问题
------------
· 小红点一直没出现？
  只有新来的邮件才会提醒。可以用别的邮箱给自己发一封试试：QQ 邮箱 15 秒内、Gmail 几秒内就会出现，
  其他邮箱最多等 2 分钟（刚开机或刚断过网时也可能要等一两分钟）。单击芸芸，它会告诉你现在有没有新邮件。

· 助手说"还没有填 API Key""API Key 不对""账户余额不足"？
  右键芸芸 → 设置… → 助手，重新粘贴 Key，点"测试并保存"；余额不足就到服务商的网站充值。

· 助手回答到一半停了，说"快超过上限了"或"这段对话加起来花到上限了"？
  这是你设的花费上限在保护你。设置 → 助手 里可以调高"每次回答最多花""每段对话最多花"，或者点"+ 新对话"重新开始。

· 遇到问题怎么反馈？
  右键芸芸 → 设置… → 关于 → 打开日志文件夹，把 yunyun.log 发给开发者，并说一下版本号（{version}）。
  日志里没有邮件内容和密码，邮箱地址也已经打码。

· 怎么升级到新版本？
  有新版本时芸芸会说一声，右键芸芸最上面的"⬆ 下载新版本"会打开下载页（也可以在 设置 → 关于 点"检查更新"）。
  下载后先退出芸芸，用新的"芸芸"文件夹替换旧的。邮箱、AI 和助手的设置、历史记录都在 %APPDATA%\Yunyun，不会丢。
  用了旁观模式又换了文件夹位置的话，到 设置… → 旁观 里点一下"重新连接"。
  如果换了文件夹的位置，到 设置… → 通用 里重新创建桌面快捷方式、重新勾选"开机时启动"。

· 怎么彻底删除芸芸？
  1. 设置… → 通用 里取消"开机时启动"；用过旁观模式的话，设置… → 旁观 里点"断开"；然后退出芸芸；
  2. 删除"芸芸"文件夹、桌面快捷方式，以及 %APPDATA%\Yunyun 文件夹
     （在资源管理器的地址栏输入 %APPDATA% 回车就能找到）；
  3. 控制面板 → 凭据管理器 → Windows 凭据，删除 yunyun-mail、yunyun-ai、yunyun-assistant 开头的条目。
  （注册表 HKEY_CURRENT_USER\Software\Yunyun 里还有几项界面设置，比如语言和芸芸的位置，很小，不删也没关系。）
