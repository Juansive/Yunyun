  - 按 Esc 或点到别的程序时只有输入框收起，卡片和打开的详情会一直留着（可以边看文档边看回答），图层跟着芸芸；
    不想看了就右键芸芸 →"隐藏卡片"，左键点芸芸再叫出来。
  - 卡片挡住东西时，按住卡片堆或详情框的空白处就能拖开，之后它跟着芸芸走；右键"卡片回到芸芸旁边"复位。
  - 收起 10 分钟没再用，只释放后台（约 300 MB），卡片还在，再问时接着同一段对话；在菜单里点"退出助手模式"才完全退出。
  - 设置 → 助手：选模型（默认最便宜的 Claude Haiku 4.5）、填 API Key（"测试并保存"不花钱，保存过的 Key 不会显示出来）；
    花费上限分"每次回答"（默认 0.1 美元）和"每段对话"（默认 0.5 美元），太低时会提醒；
    还能看到芸芸今天 / 本月 / 一共花了多少（Anthropic 不提供查余额的接口，余额请到官网看）。
  - 大脑可以换成 DeepSeek（设置 → 助手 → 服务商）：便宜很多，花费按 DeepSeek 的价格算（宁可多算一点，按高峰价）；
    设置页直接显示 DeepSeek 账户余额。DeepSeek 不能搜索网页，但能读你给的网址。
  - 芸芸的样子跟着助手变：读文件、跑命令时是"在干活"，要你确认时是"等你确认"（举手 + 问号，比较显眼）。
    助手在忙的时候来了新邮件，芸芸不会激动打断，只是小红点 +1。（现在是临时画的图，正式形象以后换）
  - 问完把输入框收起去忙别的：芸芸做完会在气泡里报一句"做完啦 · 改了 2 个文件 · $0.0040"，下面是回答的开头。
  - 芸芸被别的窗口挡住时，要你确认或者做完了，任务栏时钟上方会弹出一个小条（橙色：等你确认；蓝绿色：做完啦），
    点一下芸芸就出来了。全屏看视频、演示时不弹。
  - 对话太长时自动整理：一段对话超过约 4 万 token（设置 → 助手可以改，也可以选"不整理"），芸芸答完就把前面的对话
    整理成一段摘要，之后每一问只带着摘要——聊久了也不容易变笨，也更省钱（个别细节可能会丢）。
    卡片底部花费后面会显示"对话 2.3万/4万"（快到了变橙色），整理好了显示"前面的对话整理好了"；整理时照常可以提问。
  - 芸芸的记事本：换了一段对话也记得你。聊天、干活时她会把以后用得上的事记下来（你的偏好、项目的约定、踩过的坑），
    你说"记住……"时一定记；"关于你"的每段对话都用，项目的只在同一个工作文件夹里用。记了的那一问，卡片底部写"记了 N 条"。
    设置 → 记事本：能看、改、删、全部清空，也能关掉。只存在你的电脑上（每段对话开始时目录会发给你选的服务商）。
  - 芸芸能看屏幕了："看看我屏幕上这个报错是什么意思"——她会先说一声"我看一下屏幕哦"，截下你刚才用的那个窗口
    （需要时截整块屏幕）再回答。芸芸自己的窗口（卡片、输入框、气泡）不会被截进去，截图会自动缩小（一张约 1 分钱的零头）。
    截图默认不用问；设置 → 助手 → 勾上"截图前先问我"就每次先问你。截图会发给你选的服务商，和对话记录一起保留 30 天。
  - 输入框里能贴图片了：Ctrl+V 粘贴复制的图片，或者把图片文件拖进来，输入框上面会出现一排小缩略图（点 × 去掉），
    发送时和文字一起发给芸芸（一次最多 5 张，只发图片不打字也行）。拖进来的别的文件会变成它的路径。
  - 输入框里打了字、带着图片时，点到别的程序也不会收起了（按 Esc 才收）；去资源管理器里按住文件往回拖时，
    空的输入框也会等你松手再决定收不收——拖进来了就留着。
  - 芸芸能帮你打开软件了："帮我打开计算器""打开 VS Code"——她在开始菜单里按名字找到它，先问你（确认卡片上写着软件名），
    你同意了她才打开，并说一声"帮你打开「计算器」啦"。可以选"这次对话都允许打开它"（只管这一个软件）。
    只能打开开始菜单里有的软件；她只负责打开，不会操作软件里面。
  - 芸芸有自己的浏览器了："打开 B 站首页看看有什么"——她会打开一个 Edge 窗口（你看得见她在看什么），读完再回答。
    这个浏览器和你自己的 Chrome / Edge 分开：你在里面登录过的网站，下次她还能用；你自己的浏览器她碰不到。
    打开、读网页不用问；密码框、卡号框里的内容不会交给她看。浏览器开着时芸芸不会自动释放后台（免得把你正在看的窗口关掉）；
    浏览器要占 0.4～1 GB 多内存（看网页多重），用完把那个窗口关掉就释放了。
    第一次打开要两三秒。
  - 芸芸能在网页上点击、输入、选下拉框了："在 B 站搜一下猫""帮我把这个表单填好"。每一步先问你：确认卡片上写着网站、
    她要点的是哪个按钮 / 往哪个框里输入什么（是她自己从网页上看的）。可以选"这次对话在这个网站都允许"。
    提交表单、下单、付款、发送、发布、删除、下载这类做了就撤不回的，每次都问、标红，不能"都允许"；搜索不算。
    密码、卡号、验证码她一律不填，会请你自己在窗口里填（这些框里的内容也不会给她看）。点了打开新标签页，她会跟过去。
  - 芸芸能帮你下载文件了：每次都先问你（卡片上写着网站、哪个链接、存到哪里），文件存到你的"下载"文件夹，
    重名的不会覆盖（存成"名字 (1).zip"）。你自己在芸芸的浏览器窗口里点下载也照常存到"下载"文件夹，下好了芸芸会说一声。
