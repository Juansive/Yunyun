【下一版（还没打包）】
· 新增：芸芸说话时（头顶有气泡）换成说话的样子，嘴一张一合；睡着时说话会醒来，说完再接着睡。
  （助手在想、在干活、等你确认时还是原来那几个样子）
· 新增：设置 → 通用 →"芸芸大小"，可以把芸芸调大调小（50%～200%），拖的时候马上变，脚下的位置不动；
  气泡、小红点、卡片的大小不变，只是跟着芸芸走。
· 新增：旁观模式——你自己用 Claude Code（终端、VS Code、Claude 桌面版）时，它做完一轮、等你确认或让你选的时候，
  芸芸提醒你："Claude Code 做完了 · 项目名"，下面是它说的第一句；你正看着那个窗口时不打扰。
  芸芸被挡住时，任务栏上方弹一个小条，点一下就切到 Claude Code。设置 → 旁观 →"连接我的 Claude Code"：
  在 Claude Code 的设置里加两条 hook（改之前先备份，你自己的设置不动），"断开"只删芸芸加的那两条。
· 新增：助手模式——芸芸当你的 AI 助手（要用你自己的 DeepSeek 或 Claude 的 API Key，按用量付费，怎么申请见使用说明第四节）。
  因为带上了助手要用的 Claude Code 和浏览器驱动，压缩包从 34 MB 变成了约 200 MB。
  - 右键芸芸 →"✦ 助手模式"，芸芸脚下展开一个带淡蓝光晕的输入框，可以问芸芸问题（她会上网查资料）。
    芸芸一边想一边在头顶的气泡里说回答的开头，想的时候输入框的光晕会流动；可以随时停止。
  - 每一问一答变成一张卡片，放在芸芸旁边，用滚轮翻看；单击卡片，旁边滑出阅读框显示完整的回答，代码块可以一键复制。
  - 换个话题：卡片堆右上角"+ 新对话"，或在输入框里按 Ctrl+N。
  - 历史对话：右键芸芸 →"历史对话…"（或卡片堆右上角"历史"），按日期列出以前的每段对话，点开能看全部问答，
    点"接着聊"就回到那段对话继续（芸芸记得之前说过的，也会切回那段的工作文件夹）——前一天没做完的事第二天接着做。
    卡片堆只放当前这段对话，不会越堆越多。保留 30 天，只存在你的电脑上；设置 → 助手 →"清空历史对话"可以马上全部删掉。
    （之前没存过卡片的对话，也从 Claude Code 自己的记录里找回来了）
  - 输入框左边可以选"工作文件夹"（比如你的项目，记住最近 5 个）；换文件夹会开始新对话。
    选了文件夹，芸芸就能读里面的文件、搜索（不用问你），也会遵守项目里 CLAUDE.md 写的规矩。
    改文件、执行命令、碰文件夹以外的东西都要先问你：芸芸旁边会滑出一张确认卡片，写着她想做什么
    （命令全文；改文件时是逐行对比：红色是删掉的、绿色是新增的，带行号，只显示改了的地方），
    可以"允许一次""这次对话都允许"或"拒绝"（拒绝时可以写一句理由告诉她）。
    删文件、装软件、联网下载这类有风险的命令会标红，每次都问。点"停止"时，等着确认的都算拒绝。
  - 芸芸干活时，右键她会多一项"■ 停止助手"（输入框收起着也能停）：马上停下，正在跑的命令也会结束，等着确认的都算拒绝。
  - 想知道芸芸这一问都做了什么：打开那一问的卡片，点"▸ 芸芸做了 N 件事"，能看到她读了哪些文件、执行了哪些命令、
    每一件是不用问、你允许的还是你拒绝的。
  - 芸芸改过文件的那一问，卡片上会写"改了 N 个文件"；打开卡片点底部"↶ 撤销这次改动"，文件就恢复原样。
    （用命令改的撤销不了，请用 git；开了新对话以后也撤销不了）
  - 开着助手模式时，左键点一下芸芸就能唤出输入框，不用再去右键菜单。
  - 按 Esc 或点到别的程序时只有输入框收起，卡片和打开的详情会一直留着（可以边看文档边看回答），图层跟着芸芸；
    不想看了就右键芸芸 →"隐藏卡片"，左键点芸芸再叫出来。
  - 卡片挡住东西时，按住卡片堆或详情框的空白处就能拖开，之后它跟着芸芸走；右键"卡片回到芸芸旁边"复位。
  - 收起 10 分钟没再用，只释放后台（约 300 MB），卡片还在，再问时接着同一段对话；在菜单里点"退出助手模式"才完全退出。
  - 设置 → 助手：选模型（默认最便宜的 Claude Haiku 4.5）、填 API Key（"测试并保存"不花钱，保存过的 Key 不会显示出来）；
    花费上限分"每次回答"（默认 0.1 美元）和"每段对话"（默认 0.5 美元），太低时会提醒；
    还能看到芸芸今天 / 本月 / 一共花了多少（Anthropic 不提供查余额的接口，余额请到官网看）。
  - 大脑可以换成 DeepSeek（设置 → 助手 → 服务商）：便宜很多，花费按 DeepSeek 的价格算（宁可多算一点，按高峰价）；
    设置页直接显示 DeepSeek 账户余额。DeepSeek 不能搜索网页，但能读你给的网址。
  - 芸芸的样子跟着助手变：读文件、跑命令时是"在干活"，要你确认时是"等你确认"（举手 + 问号，比较显眼）。
    助手在忙的时候来了新邮件，芸芸不会激动打断，只是小红点 +1。（现在是临时画的图，正式形象以后换）
  - 问完把输入框收起去忙别的：芸芸做完会在气泡里报一句"做完啦 · 改了 2 个文件 · $0.0040"，下面是回答的开头。
  - 芸芸被别的窗口挡住时，要你确认或者做完了，任务栏时钟上方会弹出一个小条（橙色：等你确认；蓝绿色：做完啦），
    点一下芸芸就出来了。全屏看视频、演示时不弹。
  - 对话太长时自动整理：一段对话超过约 4 万 token（设置 → 助手可以改，也可以选"不整理"），芸芸答完就把前面的对话
    整理成一段摘要，之后每一问只带着摘要——聊久了也不容易变笨，也更省钱（个别细节可能会丢）。
    卡片底部花费后面会显示"对话 2.3万/4万"（快到了变橙色），整理好了显示"前面的对话整理好了"；整理时照常可以提问。
  - 芸芸的记事本：换了一段对话也记得你。聊天、干活时她会把以后用得上的事记下来（你的偏好、项目的约定、踩过的坑），
    你说"记住……"时一定记；"关于你"的每段对话都用，项目的只在同一个工作文件夹里用。记了的那一问，卡片底部写"记了 N 条"。
    设置 → 记事本：能看、改、删、全部清空，也能关掉。只存在你的电脑上（每段对话开始时目录会发给你选的服务商）。
  - 芸芸能看屏幕了："看看我屏幕上这个报错是什么意思"——她会先说一声"我看一下屏幕哦"，截下你刚才用的那个窗口
    （需要时截整块屏幕）再回答。芸芸自己的窗口（卡片、输入框、气泡）不会被截进去，截图会自动缩小（一张约 1 分钱的零头）。
    截图默认不用问；设置 → 助手 → 勾上"截图前先问我"就每次先问你。截图会发给你选的服务商，和对话记录一起保留 30 天。
  - 输入框里能贴图片了：Ctrl+V 粘贴复制的图片，或者把图片文件拖进来，输入框上面会出现一排小缩略图（点 × 去掉），
    发送时和文字一起发给芸芸（一次最多 5 张，只发图片不打字也行）。拖进来的别的文件会变成它的路径。
  - 输入框里打了字、带着图片时，点到别的程序也不会收起了（按 Esc 才收）；去资源管理器里按住文件往回拖时，
    空的输入框也会等你松手再决定收不收——拖进来了就留着。
  - 芸芸能帮你打开软件了："帮我打开计算器""打开 VS Code"——她在开始菜单里按名字找到它，先问你（确认卡片上写着软件名），
    你同意了她才打开，并说一声"帮你打开「计算器」啦"。可以选"这次对话都允许打开它"（只管这一个软件）。
    只能打开开始菜单里有的软件；她只负责打开，不会操作软件里面。
  - 芸芸有自己的浏览器了："打开 B 站首页看看有什么"——她会打开一个 Edge 窗口（你看得见她在看什么），读完再回答。
    这个浏览器和你自己的 Chrome / Edge 分开：你在里面登录过的网站，下次她还能用；你自己的浏览器她碰不到。
    打开、读网页不用问；密码框、卡号框里的内容不会交给她看。浏览器开着时芸芸不会自动释放后台（免得把你正在看的窗口关掉）；
    浏览器要占 0.4～1 GB 多内存（看网页多重），用完把那个窗口关掉就释放了。
    第一次打开要两三秒。
  - 芸芸能在网页上点击、输入、选下拉框了："在 B 站搜一下猫""帮我把这个表单填好"。每一步先问你：确认卡片上写着网站、
    她要点的是哪个按钮 / 往哪个框里输入什么（是她自己从网页上看的）。可以选"这次对话在这个网站都允许"。
    提交表单、下单、付款、发送、发布、删除、下载这类做了就撤不回的，每次都问、标红，不能"都允许"；搜索不算。
    密码、卡号、验证码她一律不填，会请你自己在窗口里填（这些框里的内容也不会给她看）。点了打开新标签页，她会跟过去。
  - 芸芸能帮你下载文件了：每次都先问你（卡片上写着网站、哪个链接、存到哪里），文件存到你的"下载"文件夹，
    重名的不会覆盖（存成"名字 (1).zip"）。你自己在芸芸的浏览器窗口里点下载也照常存到"下载"文件夹，下好了芸芸会说一声。


【0.5.5】2026-10-05
· 新增：AI 设置里可以选"自定义"，接入你自己的模型：在线的（DeepSeek、OpenAI 等任何兼容 OpenAI 接口的服务），
  或者你电脑 / 局域网里的本地模型（LM Studio、llama.cpp、vLLM 等）。填接口地址和模型名就行，Key 可以不填。
  填的是本机或局域网的地址时，邮件不会发到网上；填的是网上的地址时，芸芸会提醒你确认信任这个服务。


【0.5.4】2026-10-05
· 改进：AI 写的提醒更准了。只说邮件里写了的内容，会说出要你做什么、什么时候
  （比如"王老师说论文第三章要补充，下周一前发他"），能分清广告和订阅推送，不再照搬固定的说法。
· 改进：提醒里一定不会出现验证码、取件码、金额、卡号、订单号、链接这些信息（AI 写了也会被芸芸自动删掉）。


【0.5.3】2026-10-05
· 修复：0.5.2 里 QQ 邮箱的新邮件最慢要 5 分钟才出现小红点。
· 改进：QQ 邮箱的新邮件 15 秒内就会出现小红点（以前最慢 2 分钟）。
  原因：QQ 邮箱的服务器不会主动推送新邮件，一个连接打开收件箱后也看不到之后来的邮件。
  现在芸芸每 15 秒在同一个连接上重新看一眼收件箱（不用重新登录，很省）；会主动推送的邮箱（比如 Gmail）几秒内就出现。
  另外每 2 分钟的检查一直照常进行，作为兜底。


【0.5.2】2026-10-05
· 新增：实时接收新邮件（IMAP IDLE）。邮箱服务器主动通知时，小红点几秒内就会出现；
  断网后会自动重连；不支持实时接收的邮箱照常每 2 分钟检查一次。
· 已知问题：QQ 邮箱的新邮件最慢要 5 分钟才出现（下一版修复）。
