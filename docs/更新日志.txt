【下一版（还没打包）】
· 新增：设置窗口里多了"助手"页，为正在开发的"助手模式"做准备：选择模型（默认最便宜的 Claude Haiku 4.5，
  旁边写着价格）、填写 API Key、设定"每次最多花多少钱"（默认 0.1 美元）。点"测试并保存"只检查 Key 和模型，不会花钱。
  保存过的 Key 不会显示出来；要换的话粘贴新的就行。
· 新增（开发中）：右键芸芸 →"✦ 助手模式"，芸芸脚下展开一个带淡蓝光晕的输入框，可以问芸芸问题（她会上网查资料）。
  芸芸一边想一边在头顶的气泡里说回答的开头，想的时候输入框的光晕会流动；可以随时停止。
  按 Esc 或点别处输入框就收起，再右键唤出马上能用；收起 10 分钟没再用，或者在菜单里点"退出助手模式"，助手就完全退出、不占内存。
  每一问一答会变成一张卡片，放在芸芸旁边的卡片堆里，用滚轮翻看以前的回答。
  单击卡片，旁边会滑出一个阅读框，显示完整的回答；代码块右上角有"复制"按钮。
  想换个话题：鼠标移到卡片堆上，点右上角的"+ 新对话"（或者在输入框里按 Ctrl+N），芸芸就不记得之前聊的了。
  卡片只放在内存里，不保存到电脑上，关掉芸芸就清空。
  还没填 API Key 时会先带你去设置页。
· 改进：助手的花费上限分成两个："每次回答最多花"（默认 0.1 美元，快超过时芸芸自己停下）和"每段对话最多花"
  （默认 0.5 美元，到了会提醒你开个新对话）。上限设得太低时，设置页会提醒你。


【0.5.5】2026-10-05
· 新增：AI 设置里可以选"自定义"，接入你自己的模型：在线的（DeepSeek、OpenAI 等任何兼容 OpenAI 接口的服务），
  或者你电脑 / 局域网里的本地模型（LM Studio、llama.cpp、vLLM 等）。填接口地址和模型名就行，Key 可以不填。
  填的是本机或局域网的地址时，邮件不会发到网上；填的是网上的地址时，芸芸会提醒你确认信任这个服务。


【0.5.4】2026-10-05
· 改进：AI 写的提醒更准了。只说邮件里写了的内容，会说出要你做什么、什么时候
  （比如"王老师说论文第三章要补充，下周一前发他"），能分清广告和订阅推送，不再照搬固定的说法。
· 改进：提醒里一定不会出现验证码、取件码、金额、卡号、订单号、链接这些信息（AI 写了也会被芸芸自动删掉）。


【0.5.3】2026-10-05
· 修复：0.5.2 里 QQ 邮箱的新邮件最慢要 5 分钟才出现小红点。
· 改进：QQ 邮箱的新邮件 15 秒内就会出现小红点（以前最慢 2 分钟）。
  原因：QQ 邮箱的服务器不会主动推送新邮件，一个连接打开收件箱后也看不到之后来的邮件。
  现在芸芸每 15 秒在同一个连接上重新看一眼收件箱（不用重新登录，很省）；会主动推送的邮箱（比如 Gmail）几秒内就出现。
  另外每 2 分钟的检查一直照常进行，作为兜底。


【0.5.2】2026-10-05
· 新增：实时接收新邮件（IMAP IDLE）。邮箱服务器主动通知时，小红点几秒内就会出现；
  断网后会自动重连；不支持实时接收的邮箱照常每 2 分钟检查一次。
· 已知问题：QQ 邮箱的新邮件最慢要 5 分钟才出现（下一版修复）。


【0.5.1】2026-10-04  第一个发给朋友的版本
· 打包成 exe：不用安装 Python，解压后双击"芸芸.exe"就能用；附带这份更新日志和使用说明。
· 新增：拖动芸芸时会被"拎起来"，还会像小猫一样左右晃，停下来再荡两下。

  在芸芸里就能下载模型；只在处理邮件时启动，用完 20 秒就关，平时不占内存。
· 优化：内存占用减少约 13%（图片加载时缩小到显示需要的大小；原图越大省得越多）。
· 已有功能：陪你打字的动画；新邮件小红点 + 卡片堆；AI 一句话提醒（智谱免费模型等）；
  历史记录（7 天）；免打扰时段；开机时启动；桌面快捷方式；中文 / English / 日本語。
