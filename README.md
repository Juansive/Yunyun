# 芸芸（Yunyun）

一只住在你桌面上的 AI 小助手。它会陪你打字，帮你留意新邮件，用一句话告诉你"来了什么邮件"。

> 目前是开发版，形象还是占位图，正式画作在路上。

## 它能做什么

- **陪着你**：你打字时它也"敲键盘"，你停下来它就打盹；可以拖到桌面任意位置。
- **帮你看邮件**：每 2 分钟检查一次邮箱（QQ 邮箱已验证；163、Gmail 支持中）。有新邮件时，芸芸右上角出现**小红点**。
- **一句话提醒**：点小红点，芸芸用 AI 把每封邮件变成一句话，比如"嘿！你的加油发票来啦！"，以卡片的形式一张张展示。
- **不打扰你**：被别的窗口挡住时自动暂停；全屏看视频、玩游戏、放 PPT 时不弹提醒。
- **不改动你的邮箱**：芸芸看过的邮件，在你的邮箱里仍然是"未读"。
- 界面支持中文、English、日本語。

## 安装（开发版）

需要 Windows 10/11 和 Python 3.11 及以上。在项目文件夹里打开终端：

```
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m yunyun.main
```

芸芸出现后，**右键芸芸 → 设置 → 创建桌面快捷方式**。之后双击桌面上的"芸芸 Yunyun"就能启动，不用再开终端。

## 第一次使用

1. **添加邮箱**：第一次启动时芸芸会自动打开"邮箱账号"窗口（以后在 右键 → 设置 → 邮箱账号… 里也能改）。
   QQ 邮箱需要**授权码**而不是 QQ 密码：QQ 邮箱网页版 → 设置 → 账号与安全 → 开启「IMAP/SMTP 服务」→ 生成授权码。
2. **设置 AI**（可选，推荐）：添加完邮箱后芸芸会接着打开 AI 设置（以后在 右键 → 设置 → AI 设置… 里也能改）。默认用智谱的免费模型，
   去 [open.bigmodel.cn](https://open.bigmodel.cn) 注册后，在"API Keys"里创建一个 Key 填进去。
   不设置 AI 也能用，芸芸会直接告诉你"谁发来了什么标题"。

## 日常使用

| 你想做 | 怎么做 |
|---|---|
| 看新邮件 | 单击芸芸右上角的**小红点** |
| 这批邮件不想看了 | 把小红点**拖走**松手（像 QQ 那样），或 右键芸芸 → 全部标为已看 |
| 暂时不想看到小红点 | **右键**小红点；想找回来就**右键芸芸** |
| 浏览卡片 | **滚轮**或 ↑↓ 键切换；**单击卡片**展开看标题、发件人、附件 |
| 收起卡片 | 点别处、按 Esc，或再点一下小红点 |
| 芸芸被挡住了 | 双击任务栏右下角托盘里的芸芸图标 |
| 让芸芸一直在最上面 | 右键 → 设置 → 始终在上 |
| 开机自动启动 | 右键 → 设置 → 开机时启动 |
| 换个位置 | 直接拖动芸芸，下次启动还在那里 |
| 退出 | 右键 → **快速双击**"退出"（防止误点） |

小红点只数**芸芸开始帮你看邮箱之后**新来的未读邮件，以前积攒的旧邮件不会算进去。

## 隐私

| 数据 | 存在哪里 |
|---|---|
| 邮箱授权码、AI 的 API Key | Windows 凭据管理器（`yunyun-mail`、`yunyun-ai`），由你的 Windows 账户加密保护 |
| 邮箱地址、AI 服务商 | 项目文件夹里的 `config.yaml` |
| 哪些邮件提醒过 | `%APPDATA%\Yunyun\Yunyun\mail_state.json`（只有邮件编号，没有内容） |
| 日志 | `%APPDATA%\Yunyun\Yunyun\logs\`（不含邮件内容和密钥，邮箱地址已打码） |
| 语言、窗口位置等设置 | 注册表 `HKEY_CURRENT_USER\Software\Yunyun` |
| 开机启动 | "启动"文件夹里的"芸芸 Yunyun"快捷方式 |

- **发送给 AI 的内容**：只有你**点了小红点**之后，才会把邮件的发件人、标题、附件名和正文开头（最多 1500 字）发给你选择的 AI 服务商。拖走小红点清掉的邮件不会发送。
- **键盘**：芸芸只检测"你有没有在打字"，**从不记录你按了哪个键**。

## 常见问题

**小红点一直没出现？** 只有新来的邮件才会提醒，可以用别的邮箱给自己发一封试试，最多等 2 分钟。单击芸芸，它会告诉你"现在没有新邮件"。

**遇到问题怎么反馈？** 右键 → 设置 → 打开日志文件夹，把 `yunyun.log` 发给开发者。

**怎么彻底删除芸芸的数据？** 先在 右键 → 设置 里取消"开机时启动"；删除项目文件夹、桌面快捷方式和 `%APPDATA%\Yunyun`；在"控制面板 → 凭据管理器 → Windows 凭据"里删除 `yunyun-mail`、`yunyun-ai` 开头的条目；删除注册表 `HKEY_CURRENT_USER\Software\Yunyun`。
