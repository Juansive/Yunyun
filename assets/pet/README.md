# 芸芸形象素材要求（给画师）

这个文件夹里现在是程序生成的**占位图**（`tools/make_placeholders.py`）。
正式画作到了以后，**用同名文件直接覆盖**即可，不需要改代码（替换步骤见文末）。

  - 工作·敲下：每敲一下键盘换下一张，敲完约 0.09 秒后回到 `working_up.png`。

## 技术要求

1. **格式**：PNG，**透明背景**（带 Alpha 通道），颜色模式 sRGB。
2. **尺寸**：正方形画布，建议 **512 × 512 像素**，不低于 400 × 400。
3. **所有图的画布大小必须完全一致，角色在画布里的位置也要一致。**
   也就是说，身体、头的位置每张都对齐，只有变化的部位（手、表情等）不同。
   否则切换画面时芸芸会"跳一下"。建议在同一个文件里分图层画，再分别导出。
4. **四周留一点透明边**（约 5%，也就是 20–30 像素），角色不要贴着画布边缘。
5. **显示尺寸很小**：桌面上大约 160 × 160（高分屏上实际 240–320 像素）。
   所以线条不要太细（在 512 画布上建议 ≥ 6 像素），太小的细节缩小后会看不清。
6. 透明的地方鼠标点不到（会"穿透"到下面的窗口），所以角色轮廓就是可以点击、拖动的范围。
7. **右上角会叠一个小红点**（新邮件数）：在 512 画布上大约是 x 400–490、y 40–100 的区域。
   这里不要放脸、眼睛这类重要的部位（放头发、耳朵、背景小装饰没关系）。
8. 气泡和卡片是贴着画布边缘（往里约 6%）摆的，所以角色要基本撑满画布；画得太小，气泡会离角色很远。

## 托盘图标 `tray.png`

- 显示在任务栏右下角，实际只有 16–32 像素大，所以要**简洁**：只画芸芸的头像或剪影，不要细节和文字。
- 256 × 256 PNG，透明背景，主体尽量撑满画布（只留很少的边）。
- 在深色和浅色任务栏上都要看得清（可以加一圈浅色描边）。
- 没有这张图时，程序会暂时用 `idle_1.png` 代替。

## 替换步骤（给开发者）

1. 把 PNG 按上面的文件名放进这个文件夹（`assets/pet/`），覆盖同名的占位图。分层源文件不要放这里，另外保存。
2. **开发版**：重新启动芸芸就能看到（`.\.venv\Scripts\python -m yunyun.main`）。
3. **exe 版**：图片是打包时复制进 exe 文件夹的，换图后要**先退出芸芸，再重新打包**（双击 `tools\build_exe.bat`）。
   exe 的图标也会用新的 `tray.png`（没有就用 `idle_1.png`）重新生成。
4. 桌面快捷方式的图标是创建时保存的：在 设置… → 通用 里**重新创建一次快捷方式**、**取消再勾选一次开机时启动**，图标才会换。
   （Windows 有图标缓存，个别地方可能要过一会儿或重启资源管理器才更新。）
5. 必需的图（上表 ✅）缺了任何一张，芸芸会启动失败；原因写在日志 `%APPDATA%\Yunyun\Yunyun\logs\yunyun.log` 里。
