# 助手模式的形象

开着助手模式时（右键"✦ 助手模式"打开，到"退出助手模式"为止），芸芸换成这个文件夹里的形象。

- **文件名和上一层 `assets/pet/` 完全一样**（`idle_1.png`、`thinking_1.png`、`talking_1.png`……），要求也一样（见上一层的 README）。
- **这里没有的组，用平时那套的**：现在这个文件夹是空的，所以助手模式下还是平时的样子（占位）。
  画好一组放一组就行，比如只放了 `thinking_*.png`，就只有"思考"换成新形象。
- 一组里要换就整组换：放了 `idle_1.png`，平时那套的 `idle_2.png` 就不会再用。
- "在干活""等你确认"没画时先用这里的"思考"，"说话"没画时先用这里的"激动"（都没有才用平时那套的）。
- 托盘图标 `tray.png` 不放这里，一直用平时的。
- 画布大小和平时那套一样（正方形，角色基本撑满）；脚下的位置最好也对齐，打开 / 退出助手模式时才不会"跳一下"。
